# Day04 — 接口与多态

> **核心目标**：理解接口协议的实现及其在多态场景下的应用。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **接口定义** | `type Warrior interface { Attack() string }` | 定义一组行为协议，不关心具体类型 |
| 2 | **隐式实现** | `func (s Swordman) Attack() string` | 结构体只要实现接口所有方法即自动满足接口 |
| 3 | **多态切片** | `team := []Warrior{p1, p2}` | 利用接口将不同类型放入同一容器统一管理 |
| 4 | **动态错误** | `fmt.Errorf("message")` | 动态构建并返回 error 类型对象 |
