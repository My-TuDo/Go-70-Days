# Day22 — 并发锁机制

> **核心目标**：使用 `sync.Mutex` 和 `sync.RWMutex` 保护共享资源并发安全。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **互斥锁** | `mu.Lock()` / `mu.Unlock()` | 同一时间只有一个协程能访问共享资源 |
| 2 | **defer 解锁** | `defer c.mu.Unlock()` | 确保函数无论正常/异常退出都能释放锁 |
| 3 | **读写锁** | `mu.RLock()` / `mu.RUnlock()` | 读锁可共享，写锁独占，适合读多写少场景 |
| 4 | **并发竞争** | 1000 个协程同时 Inc，无锁则结果 < 1000 | 演示锁对并发安全的保证 |
