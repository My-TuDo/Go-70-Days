# Day08 — 系统指标监控

> **核心目标**：利用 gopsutil 库获取系统实时负载并进行记录。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **CPU 采样** | `cpu.Percent(time.Second, false)` | 获取指定时间窗口内的 CPU 使用率 |
| 2 | **内存监控** | `mem.VirtualMemory()` | 读取系统虚拟内存使用情况 |
| 3 | **状态心跳** | `DB.Create(&report)` | 将系统健康指标持久化到数据库 |
| 4 | **健康检查** | `sqlDB.Ping()` | 验证数据库连接是否存活 |

---

cd day08 && go run .
