# Day10 — Context 超时控制

> **核心目标**：掌握如何使用 Context 控制长时间运行任务的生命周期。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **超时上下文** | `context.WithTimeout(ctx, 3*time.Second)` | 创建一个在给定时间后自动触发取消的上下文 |
| 2 | **取消信号监听** | `<-ctx.Done()` | 阻塞监听取消指令，实现优雅退出 |
| 3 | **资源释放** | `defer cancel()` | 确保函数退出时释放 Context 资源 |
