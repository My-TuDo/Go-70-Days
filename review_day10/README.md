## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **慢指针** | `slow := 0` | 记录满足条件的待放置位置 |
| 2 | **快指针遍历** | `for fast := 0; fast < len(nums); fast++` | 遍历数组寻找目标元素 |
| 3 | **原地修改** | `nums[slow] = nums[fast]; slow++` | 在不申请额外空间的情况下修改数据 |
