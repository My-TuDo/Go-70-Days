# Day06 — JSON 与时间处理

> **核心目标**：掌握结构体与 JSON 字符串的相互转换及时间格式化。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **JSON 标签** | `` `json:"username"` `` | 控制结构体序列化后的字段名 |
| 2 | **序列化** | `json.MarshalIndent(user, "", "  ")` | 将 Go 结构体转为带缩进的 JSON 字节流 |
| 3 | **反序列化** | `json.Unmarshal(data, &newUser)` | 将字节流解析到结构体指针中 |
| 4 | **时间格式化** | `now.Format("2006-01-02 15:04:05")` | 使用经典 123456 口诀格式化时间 |
| 5 | **时间差计算** | `time.Since(u.CreatedAt).Seconds()` | 计算从某个时间点到现在的秒数 |
