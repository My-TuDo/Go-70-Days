# Day01 — 变量与基础逻辑

> **核心目标**：掌握 Go 变量声明、基础数据类型、控制流及终端交互。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **简短声明** | `name := "谢成功"` | 函数内部快速定义并初始化变量，类型由值推导 |
| 2 | **类型格式化** | `fmt.Printf("%T", var)` | 使用 `%T` 打印变量的底层数据类型 |
| 3 | **终端输入** | `fmt.Scan(&myCrystals)` | 阻塞程序并等待用户在控制台输入 |
| 4 | **多分支选择** | `switch element { case "火": ... }` | 替代繁琐的 if-else，逻辑更清晰 |
| 5 | **条件嵌套** | `if a >= b { if a >= 16000 { ... } }` | 多层条件判断的组合使用 |
