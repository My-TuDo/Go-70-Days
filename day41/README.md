# Day41 — 令牌桶限流

> **核心目标**：使用 `rate.NewLimiter` 限制任务下发速度，保护带宽。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **创建限流器** | `rate.NewLimiter(2, 3)` | 每秒生成 2 个令牌，桶容量 3 |
| 2 | **等待令牌** | `limiter.Wait(ctx)` | 获取令牌，若桶空则阻塞等待 |
| 3 | **限流效果** | 超出速率后请求排队等待 | 平滑请求流量，避免下游被突发流量打垮 |

---
