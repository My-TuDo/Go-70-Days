# Day17 — Worker Pool 工作池

> **核心目标**：通过固定数量的工作协程处理海量任务，防止内存暴涨。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **工作池模式** | 启动 N 个 worker 协程，从同个通道取任务 | 限制并发数，防止资源耗尽 |
| 2 | **通道关闭** | `close(tasks)` | 关闭任务通道，通知 worker 不再有新任务 |
| 3 | **WaitGroup 同步** | `wg.Add(1)` / `wg.Done()` / `wg.Wait()` | 等待所有 worker 完成任务后退出 |
| 4 | **defer 减计数** | `defer wg.Done()` | 函数退出时自动通知 WaitGroup 计数器减一 |
