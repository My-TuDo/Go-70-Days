# Day13 — Panic 捕获与系统容错

> **核心目标**：掌握 panic 与 recover 机制实现"打不死的监控器"。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **延迟恢复** | `defer func() { recover() }()` | 在 defer 中捕获 panic，阻止程序崩溃 |
| 2 | **错误上报** | `recover()` 返回值即为 panic 传入的值 | 获取崩溃原因用于日志记录和告警 |
| 3 | **自动重启** | 循环调用 + recover = 崩溃后自动恢复 | 即使模块内部 panic，主循环也不会停 |
