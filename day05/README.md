# Day05 — 并发编程基础

> **核心目标**：理解 Goroutine 协程、Channel 通道及同步机制。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **启动协程** | `go worker(i, mine)` | 开启轻量级并发单元执行异步任务 |
| 2 | **通道阻塞** | `data := <-mine` | 通过管道进行数据交换，具有天然同步性 |
| 3 | **通道发送** | `mine <- result` | 将结果发送到通道，供其他协程消费 |
| 4 | **管道关闭** | `close(mine)` | 告知接收方不再有新数据发送 |

---
