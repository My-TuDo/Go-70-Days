# Day25 — 错误链路追踪

> **核心目标**：使用 `%w` 包装错误，并用 `errors.Is` 追溯底层根因。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **哨兵错误** | `var ErrDatabaseDown = errors.New("...")` | 定义可被外部匹配的顶层错误变量 |
| 2 | **错误包装** | `fmt.Errorf("认证失败: %w", err)` | 用 `%w` 将底层错误包装为上层错误，保留链路 |
| 3 | **根因追溯** | `errors.Is(err, ErrDatabaseDown)` | 逐层解开包装，判断最底层的错误类型 |
| 4 | **完整链路** | `fmt.Println(err)` | 直接打印可看到多层包装的完整路径 |
