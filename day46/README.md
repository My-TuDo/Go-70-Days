# Day46 — 递归文件清理

> **核心目标**：使用 `filepath.Walk` 扫描并清理过期旧日志。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **递归遍历** | `filepath.Walk(targetDir, walkFn)` | 递归扫描目录下的所有文件和子文件夹 |
| 2 | **判断目录** | `info.IsDir()` | 区分当前遍历的是文件还是目录 |
| 3 | **获取修改时间** | `info.ModTime()` | 获取文件最后修改时间，用于判断是否过期 |
| 4 | **条件删除** | `if age > 1*time.Hour { os.Remove(path) }` | 超过保留期限的文件自动清理 |

---

## 🧪 运行方式

```bash
cd day46/file_walker && go run .
```
