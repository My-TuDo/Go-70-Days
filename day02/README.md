# Day02 — 容器与循环控制

> **核心目标**：掌握切片（Slice）、映射（Map）及遍历循环的使用。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **切片操作** | `append(slice, "item")` | 动态扩容切片并添加新元素 |
| 2 | **迭代遍历** | `for i, v := range slice` | 使用 range 关键字同时获取索引与值 |
| 3 | **映射存储** | `make(map[string]int)` | 使用键值对存储具有关联性的数据 |
| 4 | **Map 查询** | `p, exist := powers[name]` | 检查 key 是否存在并获取值 |
| 5 | **切片字面量** | `weapons := []string{...}` | 直接初始化切片的方式 |
