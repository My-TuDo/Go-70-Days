# Day21 — 反射机制

> **核心目标**：使用 `reflect` 包在运行时动态获取结构体信息与标签。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **获取类型** | `reflect.TypeOf(s)` | 获取变量的运行时类型信息 |
| 2 | **获取值** | `reflect.ValueOf(s)` | 获取变量的运行时值信息 |
| 3 | **遍历字段** | `t.NumField()` + `t.Field(i)` | 遍历结构体的所有字段，获取名称/类型/标签 |
| 4 | **读取标签** | `field.Tag.Get("sre")` | 从字段标签中提取自定义元数据（如 `sre:"host"`） |
| 5 | **类型校验** | `t.Kind() != reflect.Struct` | 判断传入的接口是否为目标类型 |
