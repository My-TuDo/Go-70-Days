# Day18 — Select 多路复用监控

> **核心目标**：使用 `select` 同时监听多个通道信号及超时检查。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **多路复用** | `select { case <-ch1: ... case <-ch2: ... }` | 同时监听多个通道，谁先就绪就执行谁 |
| 2 | **超时保护** | `case <-time.After(3 * time.Second)` | 内置超时机制，防止无限等待 |
| 3 | **非阻塞探测** | select 配合 goroutine 实现并发检测 | 多个监控任务同时进行，互不阻塞 |
