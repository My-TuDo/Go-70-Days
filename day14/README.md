# Day14 — 接口类型断言

> **核心目标**：使用类型断言识别接口背后的实际数据类型。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **类型断言** | `val, ok := data.(string)` | 安全地尝试将接口转换为具体类型，ok 表示是否成功 |
| 2 | **类型判断** | `fmt.Printf("%T", data)` | 使用 %T 打印变量的运行时类型 |
| 3 | **多类型分支** | `if val, ok := data.(int); ok { ... }` | 依次尝试不同断言，根据实际类型分别处理 |
