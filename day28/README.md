# Day28 — Viper 配置管理

> **核心目标**：利用 Viper 库实现环境变量自动绑定与默认值配置。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **设置前缀** | `v.SetEnvPrefix("MHY")` | 防止多个程序环境变量冲突（如 `MHY_APP_PORT`） |
| 2 | **自动绑定** | `v.AutomaticEnv()` | 自动读取所有匹配前缀的环境变量 |
| 3 | **默认值** | `v.SetDefault("app_port", "8080")` | 即使外部未设置，程序也有保底配置 |
| 4 | **解压到结构体** | `v.Unmarshal(&conf)` | 将读取的配置映射到 Go 结构体中 |

---
