# Day03 — 结构体与指针

> **核心目标**：理解复合类型结构体及其指针方法对数据的修改。

---

## 📌 知识点归纳

| # | 概念 | 关键代码 | 一句话说明 |
|---|------|----------|-----------|
| 1 | **结构体定义** | `type Player struct { Name string; Level int }` | 自定义复合数据类型，聚合多个字段 |
| 2 | **结构体嵌套** | `Weapon struct { Name string; Damage int }` | 在结构体中直接定义并嵌套子结构 |
| 3 | **指针接收者** | `func (p *Player) levelUp()` | 传递地址以在方法内修改原始对象的值 |
| 4 | **地址打印** | `fmt.Printf("%p", p1)` | 使用 `%p` 查看对象在内存中的实际地址 |
| 5 | **取地址创建** | `p1 := &Player{...}` | 创建结构体指针，直接操作原对象 |
